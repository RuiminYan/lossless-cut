# LosslessCut — frame-counting fork

This is a fork of [mifi/lossless-cut](https://github.com/mifi/lossless-cut) that adds a **frame-counting** workflow used by speedcubing competition organizers to verify timer results against the recorded video.

**Usage:** see [docs/frame-count.md](docs/frame-count.md).

Everything else works exactly like upstream LosslessCut — refer to the upstream [README](README.md) and [docs/](docs/) for the rest.

## Branches

- `master` — kept in sync with upstream `mifi/lossless-cut:master`. Don't commit here.
- `feature/frame-count` — this fork's work lives here (default branch).
